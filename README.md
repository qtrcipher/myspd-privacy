# MySpd — Privacy Policy · سياسة خصوصية سرعتي

Privacy policy for the **MySpd** (سرعتي) iOS internet speed test app, hosted on GitHub Pages for use as the App Store privacy policy URL.

- **Live page:** https://qtrcipher.github.io/myspd-privacy/
- **Contact:** hamam@gccapps.com

Summary: MySpd collects **no** personal data — no accounts, no ads, no analytics, no tracking. Test traffic goes directly to Cloudflare's public speed-test service; results are stored only on the user's device.
